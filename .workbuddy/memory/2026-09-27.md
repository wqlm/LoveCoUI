### 踩坑记录

1. **`imageio-ffmpeg` 拿 ffmpeg 二进制最快**：`pip install imageio-ffmpeg` 后
   路径是 `.../site-packages/imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v7.1`。
   本机没有 brew，也没有系统 ffmpeg。
2. **ffmpeg 参数顺序**：`-frames:v N` 放在第二个 `-i` 之前会被当成「音频输入的选项」→
   报错 exit 234。要用输出选项 `-t <duration>`。
3. **`npm install puppeteer` 会卡在下载 Chromium**（国内网络），10 分钟才 30MB。
   改用 `puppeteer-core` + 本机 Chrome 的 `executablePath`。
   可用 Chrome：`/Applications/Google Chrome.app/...`、
   `~/Library/Caches/ms-playwright/chromium-1246/chrome-mac-arm64/Google Chrome for Testing.app/...`
4. **沙箱会拦 Chrome 启动**：Chrome 启动/退出时会删
   `/private/var/folders/**/com.google.Chrome.code_sign_clone/**` 和
   `~/Library/Application Support/Google/RLZ/RlzStore.plist`，沙箱规则 `**` 直接拒绝，
   Chrome 起不来。**Agent 环境里渲染不了，必须让用户在自己终端跑 `./run.sh`。**
5. **zsh 里别用 `LINES` 当数组名**，它是 shell 特殊变量，赋值报
   `attempt to assign array value to non-array`。改用 `TEXTS`。
6. **逐帧截图别用 `fs.rmSync(frames)` 清目录**，会触发 safe-delete 批量删除守卫。
   改成直接覆盖 + ffmpeg `-t` 限长即可。

### 量化取色的小技巧

别靠眼睛估颜色/坐标。用 Pillow + numpy 按「阈值 + bbox」量：
卡片白 → `(px > 246).all()`；蓝色开关 → `B - R > 90`；绿色对勾 → `G - R > 40 and G - B > 40`。
比人眼准，也快。
