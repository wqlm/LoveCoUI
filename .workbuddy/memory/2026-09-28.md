## LoveCo 教学视频：换手势图标 + 配音换 edge-tts

工程：`video-tutorial/`

### 1. 手势图标重做（第二版）

上一版（多形状拼 + 同色粗描边）在 2x 下看像**爪子**，用户判"太丑"。根因：`fill`/`stroke`
同色会把每个子形状膨胀一圈，外轮廓的凹口全被填平。这次改为**一条闭合 path 画整只手**：

```
viewBox="0 0 48 60"，指尖 (22,3)
M17 27 L17 8 A5 5 0 0 1 27 8 L27 23            ← 食指
A4.2 4.2 0 0 1 35.4 23 A4.2 4.2 0 0 1 43.8 25.5 ← 两处指节隆起
C …（掌外轮廓）… C 5 34.2 9 31.2 13.2 32.6 … Z   ← 掌 + 拇指
```
显示 44×55（缩放 0.9167）→ `#cursor width/height = 44/55`、`transform-origin` 和
`TIMELINE.hotspot` 都改成 `[20.17, 2.75]`。

选型方法：从 jsDelivr 拉了 bootstrap-icons / material-symbols / phosphor / mdi 共 14 个
现成手势图标，搭候选页（2x 尺寸 + 圆角开关作参照物）截图对比。教训：**成片是 2x 渲染的，
图标必须在 2x 下看**，1x 看着行的在 1280 宽下会糊。`api.iconify.design` 在本机连不上，
jsDelivr 可以。

新增 `shot2x.mjs`：CDP + `deviceScaleFactor=2` + `Page.captureScreenshot.clip`，
用来截「成片尺寸的局部」验收图标/配色。

### 2. 配音从 macOS `say` 换成 edge-tts

用户反馈"声音合成太机械"。`say` 是拼接式共振峰合成，音调平，中文就是机器人念。
换成 **edge-tts**（微软 Edge 神经网络语音，免费无 key）：`pip install edge-tts`，
默认 `zh-CN-XiaoxiaoNeural`。

`make-voice.sh` 重写：
- 引擎 `auto | edge | say`，edge-tts 找不到就回落 `say`（`ENGINE=say` 可强制）。
- **掐首尾静音**：`silenceremove…,areverse,silenceremove…,areverse`。
  edge-tts 的 mp3 前后各带几百毫秒静音，掐掉后 2.30s 的句子只剩 1.63s ——
  **原本放不下的段现在放得下了，`RATE` 从 +20% 回到 0%**（模型原生韵律最自然）。
- 合成完逐句打印「到 XXXms（段末 YYYms）」并校验是否溢出 `SLOTS`，超了报警。
- 已装依赖：`/Users/wqlm/.workbuddy/binaries/python/envs/default/bin/edge-tts`。

`run.sh` 增加：`voice.m4a` 缺失时自动先合成；`REVOICE=1` 强制重合成。
（注意别用 `VOICE=1`，`VOICE` 是传给 make-voice.sh 的音色名。）
